## 已覆盖的边界

- 显式停用、无 mvp 配置时的上游兼容行为、ready 与操作者校验、评论按角色覆盖。
- 状态目录与源码/工作区分离、重复领取、编码前受限释放、重启后保持阻塞。
- 固定模型、关闭平台动态工具、独立只读 Review、结构化审查结论。
- 编码异常、检查失败/超时、候选 SHA 或 Git 元数据变化、基线变动均阻断交付。
- 新分支发布、已有分支竞争、PR 身份不匹配及网络不确定时保留 publish_pending；只读对账。
- 工作区 after_run 生命周期、上游重试时钟及人工处理提示。
